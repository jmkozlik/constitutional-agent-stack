**Proposal D — spec-declared citations, compiled as excerpts.** A node may
declare what governs it; the join compiles the named excerpt verbatim from
the pinned commit into a `## Governing [provenance: verbatim at <commit>]`
section. Same discipline as `surface`: the spec declares, the join
compiles, nothing is invented, and the budget is bounded by what was
declared rather than by whole documents.

```diff
 - id: symbol_table
+  governing:
+    - "docs/brief.md#1. Symbol table"
+    - "docs/brief.md#Notes for the implementer"
```

Anchors are markdown headings; the excerpt is that heading's section. A
missing anchor at the pinned commit is a compile error, not a silent
omission — the same "flag, don't guess" rule the analyzer runs on.

validation dispatches the attestation bar is "does the shipped suite
exercise done_when", which the executor cannot judge without the test
source; 004, 006 and this round all logged it. A node may declare
`verified_by: [tests/test_indexer.py, …]`, carried verbatim in **executor
packets only** — never tester (P6). At 24% this is the one that genuinely
spends budget, so it is proposed separately: D can land without E.

dispatch tell us whether E is needed before paying for it.
