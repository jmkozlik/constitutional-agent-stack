# Join v0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox syntax.

**Goal:** Step 2 of the harness build order (`harness/README.md`): resolve a spec node's `writes` against the analyzer's symbol table, compute levels and collisions at symbol precision, and assemble one context packet a fresh agent could work from with no search tool.

**Architecture:** One module, `harness/join.py`, importing `harness.speccc` (spec mechanics: E01–E05, levels, plan hash — already built and untouched) and `analyzer.indexer.build_index` (the index). The join adds what needs the analyzer: E06, an undeclared same-level read-write check, W02 low-confidence serialization, and packet assembly per ARCHITECTURE §(2).

**Tech Stack:** Python 3.13; pyyaml (already required by speccc.py, now a `harness` extra). Tests: pytest.

## Global constraints

- Deterministic: same spec + same commit → byte-identical packet and plan output. No timestamps, no dict-order leaks. Packet carries `packet_hash` (sha256 of body) for replay (ARCHITECTURE P-eval "packet-hash replay").
- speccc.py is Rokko's artifact — imported, never modified.
- Identity bodies are files (`harness/identities/*.md`), included verbatim (ARCHITECTURE (2): "written once per role and frozen").
- Everything either resolves or throws/flags. A writes entry that cannot be located is E06, never skipped.

## Design decisions

**JD1 — writes resolution.** A `writes` entry is a repo-relative file path, resolved against `index["files"]`. Missing → `[E06] UNRESOLVED_SYMBOL` (throw, listing node and entry). Resolved → the entry's symbols are every index record with `file == entry` (possibly zero, e.g. `__main__.py`).

**JD2 — symbol-level plan checks** (over speccc's levels):
- `[E08] UNDECLARED_EDGE` (new, extends Appendix A; per Appendix B "assume an edge" doctrine): same-level nodes A,B where a symbol in A's writes has a `referenced_by` site located in B's writes files (or vice versa) — they cannot run in parallel and the spec does not say so. Error, exit 1, naming the symbol and site; remedy printed: declare the reference or restructure.
- `[W02] LOW_CONFIDENCE`: a node whose writes files contain a low-confidence symbol or an unresolved record — "unresolvable region; forces serialization" naming file + reasons, and listing the same-level peers it must serialize against.
- W01/W03 pass through from speccc unchanged.

**JD3 — packet shape** (role `executor`), one markdown document, sections in identity→task→state order (the cache boundary, ARCHITECTURE (2)):
1. Header: `packet_hash` (computed over everything below it), commit, spec dir, plan hash, node id, role.
2. `## Identity [provenance: fixed]` — `harness/identities/executor.md` verbatim + tool list line.
3. `## Task [provenance: spec, verbatim]` — node id, one_liner, done_when, open, and the writes list labeled as the exhaustive write scope.
4. `## State — compiled [provenance: verified at <commit>]`:
   - **Write scope as it exists**: per file, every symbol (dotted path, kind, signature, lines, confidence).
   - **Interfaces you consume**: for each declared dependency node, its writes files' symbols — path, kind, signature only (surface, not bodies).
   - **Callers of your scope**: per symbol, every `referenced_by` site (`file:line in <symbol> args=(...)`, ambiguity marks) — who breaks if you change a signature.
   - **Unresolved sites in scope**: the records, with the brief's "assume an edge to everything here" framing.
   - **Coverage statement** (P4): what was compiled (file list, index size, commit), and the norm: "anything not listed was not searched — missing means query (request_mem), never build."
5. `## State — handoff [provenance: agent-authored, claim not fact]` — empty in v0, section present so the shape is stable.

**JD4 — blind tester packet** (P6): identity (`harness/identities/tester.md`) + Task section only — assembled from the spec node alone; no compiled code state, with an explicit exclusion note. The executor's worktree/codebase is structurally absent, not merely elided.

**JD5 — CLI.** `python -m harness.join plan [--specs harness/specs] [--repo .] [--commit REV]` → compiled plan + resolution report + warnings, exit 1 on any E-grade. `python -m harness.join packet <node-id> [--role executor|tester] [-o FILE]` → packet to stdout or file. Exit codes: 0 clean, 1 E-grade or unknown node/role.

**JD6 — provenance tags** (P3) are in-band section headers, not a legend. v0 uses `fixed`, `spec, verbatim`, `verified at <commit>`, `agent-authored`. `spec-only`/`compressed` arrive when packets start abridging — YAGNI now.

## Post-red-team amendments (JA1–JA9)

Three critics (workflow `wf_5b2ddb10`) returned 18 findings; all accepted.
Where they conflict with JD1–JD6 above, the amendment wins.

**JA1 — the printed plan is the safe plan.** W02 (and JA3's W04) do not merely
warn: the join post-processes speccc's levels, splitting implicated nodes into
deterministic sub-levels (`2.0`, `2.1`, …) so the printed structure never
asserts parallelism the doctrine forbids. The join's plan hash is computed
over the adjusted structure. Exit stays 0 — lost throughput, not an error.

**JA2 — writes entries that don't exist are the normal case, not E06.** An
entry absent from `index["files"]` resolves as `to_create` (zero symbols;
packet renders "does not exist at commit — you are creating this file" — the
`spec-only` provenance class arriving early because step 3 needs it). Non-`.py`
entries resolve as `opaque` (Python-only index). E06 is reserved for
uninterpretable entries: absolute paths or paths escaping the repo root.
Resolution reports name the index root/commit/file-count so a wrong `--repo`
self-diagnoses.

**JA3 — E08 splits by confidence.** Confidently-resolved same-level
cross-references → E08 error (the symbol-precision read-write extension of
E05 — the Appendix B citation is dropped; that appendix prescribes
serialization, which is what the ambiguous case gets). Ambiguous-only
cross-references → `W04 AMBIGUOUS_EDGE`: assume an edge, serialize via JA1.

**JA4 — interfaces are computed from the index, not spec edges.** "Interfaces
you consume" = every symbol outside the node's write scope referenced from
inside it, tagged `declared` (its owning node is in the transitive closure of
`references`) or `UNDECLARED` (a spec-quality signal, printed as such). A
consumed symbol whose owner is not an ancestor also emits `W05 REVERSE_EDGE`
in `plan` (the as-built repo has one: indexer.py consumes refs.py). Declared
transitive dependency surfaces are unioned in so greenfield nodes still see
what exists.

**JA5 — symbols carry docstrings.** The analyzer records `doc`
(`ast.get_docstring`) per symbol; interface surfaces include it — a signature
alone cannot convey a returned data structure. `build_index`'s own docstring
now states the index schema, so any packet consuming it carries the schema.

**JA6 — cache boundary restored.** No header. Packets begin with the Identity
section (byte-identical across every dispatch of a role); metadata
(node, role, commit, plan hash, packet_hash) lives in a one-line trailer,
`packet_hash` computed over everything above it. Spec-dir spelling never
reaches hashed bytes.

**JA7 — Task variants never share content.** Executor Task = one_liner +
write scope + open items. Tester Task = done_when rendered as guarantees to
verify — no one_liner, no writes list, no open items (P6: the tester packet
must not prime module layout or the author's undecided questions).

**JA8 — replayability is explicit.** `packet` pins a commit (default HEAD);
`--worktree` is allowed but stamps `worktree (uncommitted, not replayable)`
into the trailer and hash. `plan` defaults to worktree mode and prints which
index it used. Identity files are tool-free; the tool list is a per-role
constant in join.py explicitly marked as the hook-manifest stub. Coverage
gains one line: `verify with: python -m pytest`.

**JA9 — determinism is tested across processes,** with differing
`PYTHONHASHSEED`, not just twice in one process. Verification (Task 5) probes
BOTH roles' packets; tester-packet misses (e.g. done_when naming no invocable
surface) are logged as Phase 0 data, not silently patched.

## Verification round + probe telemetry (post-build)

Workflow `wf_480d138a` (2 hunters, 3 blind sufficiency probes, per-finding
skeptics). Six defects confirmed and fixed (normalized-path resolution with a
join-level E05 for alias collisions; packet refusing E-grade specs; dispatch
hash in the trailer; clean errors for missing/empty specs dirs, non-string
payloads, bad repo/commit; ambiguous-attribution marks in consumed surfaces
and W05 phrasing). Executor packets now carry write-scope source bodies — a
probe showed signatures alone cannot support *modifying* a file.

**Phase 0 / spec-format telemetry from the probes (recorded, deliberately not
patched here — they are gaps in the spec system, not in packet assembly):**

- **Spec nodes state end-states, not deltas.** Both executor probes found the
  write scope already implementing the one_liner and correctly concluded
  "halt and file a defect: what is the work?" A maintenance dispatch needs a
  delta channel — failing test, defect report, or the handoff section that
  step 4's kill-and-respawn protocol owns.
- **done_when names outcomes but no invocation surface.** The blind tester
  cannot name the thing to invoke, so the guarantees are semantically
  test-shaped but mechanically untestable — precisely the bar WRAP.md sets
  ("done_when inherits the interface-spec bar: precise enough to test from
  alone"), which `analyzer.yaml` does not yet meet. Spec-format decision for
  Rokko: an invocation-contract line per node, or done_when conventions.
- **The identity references protocols that do not exist yet** (request_mem
  calling convention, proposal delivery format). Owned by the hook manifest /
  step-3 protocol, not the packet.
- **For maintenance work, test assertions are the real spec.** Packets name
  test callers but not test bodies; whether test sources ride in the packet
  is a budget question (W03 territory), deferred.

## Spec format v0.2 gate (2026-08-07, ratified change)

v0.2 as ratified: nodes stay declarative end-states; the delta is compiled at
dispatch (surface × index) and never spec-authored or handoff-carried;
`surface:` is the exported contract done_when is tested through (W06 when
absent); tester packets are task + surface only. `analyzer.yaml` surfaces
seeded verbatim from the index — all five nodes compile to
`delta: empty (validation-only)` against the as-built repo, which is the
proof no signature was invented.

**Gate: the identical three-probe run** (workflow `wf_0bc7176a`, packets at
commit `baad6d5`, packet-only, no tools):

| probe | v0.1 verdict | v0.2 verdict |
|---|---|---|
| executor: symbol_table | insufficient | **sufficient_with_gaps** |
| executor: affected_symbols | insufficient | **sufficient_with_gaps** |
| tester: affected_symbols | insufficient | **sufficient_with_gaps** |

The v0.1 blockers closed: the delta block answers "what is the work" (both
executor probes correctly read empty delta as a validation-only dispatch),
and the tester can now name the thing to invoke. No verdict is insufficient,
so per the gate rule the remaining gaps are recorded as format findings, not
hand-patched:

- **F1 — executors never see done_when.** The kit routes done_when to the
  tester contract only, so a validation-only dispatch cannot check the code
  against its own acceptance bar (both executor probes' top miss). Decision
  needed: does executor Task carry done_when, or is validation solely the
  tester's job by design?
- **F2 — surface names callables but not data shapes or error semantics.**
  The tester can invoke `compute_affected` but cannot assert on it:
  `AffectedReport`'s fields are unspecified, and guarantee 4's "is an error"
  names no error surface (the only exported exception is GitError, which is
  git plumbing). Surface likely needs a type/error stanza — e.g. dataclass
  field lists and the declared failure channel.
- **F3 — the closure protocol is still outside every packet** (proposal
  format, defect-filing channel, request_mem invocation shape, what
  "complete" means for a validation-only dispatch). Owned by the step-3
  spawn protocol / hook manifest; flagged every round, unchanged by v0.2 as
  expected.
- **F4 — packets cite the brief/plan documents but do not carry them**;
  spec-conformance validation is currently self-certified by code comments.
  A packet exhibit for cited governing docs is a budget question (W03).

## Spec format v0.3 — ratification and interpretation (2026-08-07)

**Ratified rulings (verbatim intent):** (1) done_when routes to BOTH roles,
verbatim; executor Task carries it above the DELTA block; role asymmetry is
state only (executor: compiled chunks + delta; tester: task + surface, P6);
for a validation-only dispatch done_when is the checklist the executor
attests or files against. (2) surface becomes three sections —
callables / types / errors — with the closure rule that anything done_when
names must resolve to a surface entry; types carry field lists (owned types
authored, built ones seeded byte-for-byte from the index; foreign types
resolve from the owning node's surface at packet build); errors are a named
exported observable + raise condition (git plumbing does not satisfy an
analysis-semantics guarantee); DELTA extends to types
(present/absent/shape-mismatch) and errors (present/absent); W07 warns when
done_when references a type or error absent from surface. The
affected_symbols guarantee-4 error surface is proposed as a spec diff for
Rokko's ratification — never self-ratified. (3) gitio extracts into its own
atom node owning its symbols, with real edges from its consumers.

**Interpretation decisions (I1–I8), open to red-team before build:**

- **I1 — yaml shape.** `surface:` becomes a mapping with optional list-typed
  keys `callables`, `types`, `errors` (each entries are strings). W06 now
  fires when done_when exists and `surface.callables` is empty/absent.
- **I2 — type entry format.** A class type renders as
  `dotted.path.Type(field: ann, field2: ann = default, ...)` — field list in
  class-body order, rendered with the same display convention as parameter
  lists. Seeding byte-for-byte requires the index to carry class fields, so
  the analyzer gains `fields` on class records (annotated class-body
  targets, verbatim unparse of annotation and default). A module-level type
  alias (e.g. `Range = tuple[int, int]`) is not indexable without deciding
  the brief's open constants question, so alias entries render
  `dotted.path.Name = expr`, delta-match as `unindexed (module-level alias;
  brief open question)`, and never count as outstanding.
- **I3 — error entry format.** `dotted.path.Observable: <condition text>` —
  the path must name an indexed symbol (exception class, property, field);
  delta checks presence of the observable only (conditions are prose).
- **I4 — W07 heuristic.** Per done_when item: (a) any internal-CamelCase
  token (`[A-Z][a-z0-9]*[A-Z]\w*`) not appearing in any surface entry
  string → W07; (b) the word "error(s)" appearing while `surface.errors` is
  empty → W07. Sentence-initial capitalization never matches (a), so prose
  stays quiet.
- **I5 — foreign type resolution.** At packet build, for every OTHER node's
  `types` entry whose terminal type name appears as a word in this node's
  callable entries, the type is included in the packet's surface types
  labeled `[from <node>]`.
- **I6 — surface reassignment with the gitio split.** gitio (new atom):
  callables changed_files/list_py_files/read_files/resolve_commit; types
  `analyzer.gitio.Range = tuple[int, int]` (authored alias); errors GitError
  (raised when a git command fails). These leave affected_symbols' surface.
  IndexLoadError and ParseFailure move from callables into symbol_table's
  errors with conditions. affected_symbols keeps callables
  compute_affected / render_report / AffectedReport.has_error, gains types
  AffectedReport + Row (seeded from index fields), and its errors section
  stays EMPTY pending guarantee-4 ratification — W07 fires there by design
  until Rokko rules.
- **I7 — edges.** references gain gitio at every consumer the index shows:
  symbol_table, affected_symbols, analyzer_cli (GitError import).
  affected_symbols' writes shrink to [analyzer/affected.py]. Predicted
  levels: gitio 0; symbol_table 1; reference_map 2; unresolved_sites +
  affected_symbols 3 (W02-split); analyzer_cli 4.
- **I8 — predicted W05 outcome, stated up front.** The gitio W05 clears.
  The refs W05 does NOT clear from this restructure: it stems from
  indexer.py (symbol_table's writes) consuming refs.py (reference_map,
  downstream) — untouched by the gitio extraction. Fixing it needs an
  ownership move (e.g. an index-assembly node downstream of reference_map),
  which is a spec restructure for ratification, not something this change
  self-decides. The before/after plan output will show one W05 remaining.

**Red-team amendments to the interpretation (workflow `wf_bf5e9d4f`, 15
findings, all accepted):**

- **I0 (new) — clause 1's home.** Executor Task renders: node, one_liner,
  write scope, surface (three labeled subsections), open, then
  `done_when (attest against, or file against, on a validation-only
  dispatch):` verbatim, immediately above the DELTA block. This supersedes
  JA7's content-disjointness for done_when ONLY; one_liner/writes/open stay
  executor-only and the tester stays task + surface per P6.
- **I1 (amended) — the ratification amends speccc.** Ruling clause 2 changes
  the spec format speccc validates, so speccc.OPTIONAL's `surface` becomes
  dict and W06 moves to `surface.callables` — recorded here as ordered by
  the ratification, not silently done (v0.2 precedent: 1e38cdf). join's
  element validation recurses the three sections, rejects unknown keys, and
  turns the YAML colon trap (an unquoted `path: condition` entry parsing as
  a one-key mapping) into an E01 naming the quoting requirement.
- **I2 (amended) — constructor-shaped types.** A class with no annotated
  class-body fields seeds its field list byte-for-byte from its `__init__`
  record's signature minus `self` (the index carries it). So
  `analyzer.refs.Resolver(symbols: dict[str, list[dict]], tables: dict[str,
  'ImportTable'])` is seedable, not invented. Delta type-matching accepts
  either form; `fields` is read with .get() (function records carry none).
- **I3 (amended) — error entries parse at the FIRST ": "** (condition prose
  may contain colons), never through the callable parser. A path of the
  form `Owner.field` resolves through the owning class record's fields list
  (`field:` prefix match); properties resolve as indexed defs. Conditions
  are authored per-callable and accuracy-checked against the code — e.g.
  ParseFailure is raised by extract_symbols while build_index records a
  parse_error unresolved site instead, and load_index re-raises
  FileNotFoundError for missing files.
- **I6 (amended) — no back-door ratification.** `AffectedReport.has_error`
  is NOT added to callables (doing so would enact the guarantee-4 option
  the ruling reserves). affected_symbols surface = callables
  {compute_affected, render_report} + types {AffectedReport, Row} + errors
  {} with W07 firing until ratification. ParseFailure is an *addition* to
  symbol_table's errors, not a move. reference_map's types gain Resolver
  and ImportTable (constructor-shaped, I2), leaving callables
  {collect_references, ImportTable.from_module} — which lets I5 carry
  Resolver into unresolved_sites' packet.
- **I9 (new) — the gate, operationally.** Regenerate both roles' packets at
  the new commit; run the identical three probes (executor:symbol_table,
  executor:affected_symbols, tester:affected_symbols), packet-only, no
  tools; record verdicts in the gate table; F3 stays step-3-owned; any
  surviving non-F3/F4 gap stops the line as a format finding. The
  guarantee-4 proposal diff ships with the report (PROPOSED, unapplied).
- **Recorded residue (format findings, not patched):**
  **F5** — dict-record shapes (reference map records, unresolved records,
  confidence marks) are outside I2's type system, so unresolved_sites' and
  reference_map's remaining guarantees fail the closure rule with no W07
  trigger (no CamelCase token, no "error" word). Needs a convention
  (authored pseudo-type entries for record shapes) — queued for
  ratification. **F6** — indexer.py consumes the private `gitio._git`;
  after the split, symbol_table's declared gitio edge is satisfied partly
  outside gitio's exported contract. Candidate fixes (public raw-git
  callable, or the listing moves into gitio) noted, not self-decided.

## v0.3 gate (2026-08-07) — verdicts and STOP ruling

Identical three-probe protocol (workflow `wf_90b348e2`, packets at `1e38cdf`+,
packet-only, no tools):

| probe | v0.1 | v0.2 | v0.3 |
|---|---|---|---|
| executor: symbol_table | insufficient | sufficient_with_gaps | **sufficient_with_gaps** |
| executor: affected_symbols | insufficient | sufficient_with_gaps | **sufficient_with_gaps** |
| tester: affected_symbols | insufficient | sufficient_with_gaps | **sufficient_with_gaps** |

v0.3 closed what it targeted: executors read done_when as their attestation
checklist and traced every bullet to code or evidence; the tester now has
callables, field shapes, and (for three of four guarantees) a workable
assertion path. Surviving gaps classified per the gate rule:

- **F3-class (carved out, step-3-owned):** attestation/proposal format,
  defect-filing mechanism, request_mem convention, tester harness
  conventions. **F4-class (carved out, recorded):** test bodies and cited
  governing docs not carried in packets.
- **F7 (NEW — stop-grade): a done_when bullet with no surface path.**
  symbol_table's "Given a symbol path, returns its definition and signature"
  resolves to NO surface callable (nothing takes a symbol path), and W07 is
  structurally blind to it (no CamelCase token, no error word). The closure
  rule needs an operation-level check — every done_when bullet must name at
  least one surface callable it is exercised through — or the bullet needs
  rewording/a lookup API decision. Sibling of F5.
- **F8 (NEW — stop-grade): shape is not contract.** The tester refuses (
  correctly) to invent: Row.category's value domain ('moved'/'signature'/...),
  Row.callers' element format, Row.path's granularity, and the untyped
  `repo` parameter that the surface inherits verbatim from the code. Types
  carry field lists but the guarantees invoke value semantics no surface
  section declares. Candidate format extension: value-domain annotations on
  type fields (authored, like error conditions) — for ratification.
- **F9 (minor):** the spec never states the analyzer's language scope
  (fixture authors must presume Python from context; the brief says it, the
  spec doesn't).
- **Anticipated, not a finding:** guarantee 4's error channel — awaiting the
  ratification the proposal below requests. W07 fires on it by design.

**Per the gate rule ("if any gap survives that is not F3 or F4, stop") the
line is STOPPED before step 3.** The write-fence (separately ordered) is
built and evidenced; step 3 remains gated on F7/F8 and the guarantee-4
ratification.

## PROPOSED spec diff — affected_symbols guarantee-4 error surface (unapplied)

**Option A (recommended — ratifies the as-built observable, zero code
change, delta stays empty):**

```yaml
    errors:
      - "analyzer.affected.AffectedReport.has_error: true when any row is
         error-grade; analyzer_cli maps it to exit 1 (exit codes are
         analyzer_cli's scope, carried here as prose only)"
      - "analyzer.affected.Row.error: set on a deleted row whose old-index
         referenced_by is non-empty — deleting a symbol with recorded
         callers is the only error-grade condition today"
```

Both paths delta-verify: has_error is an indexed property; Row.error
resolves through Row's field list (I3 as amended). Expressibility caveat
(red-team): the exit-1 channel itself is not an affected_symbols
observable — if wanted as testable surface it belongs on analyzer_cli.

**Option B (dedicated exception):** `analyzer.affected.DeletedWithCallersError:
raised by compute_affected when a deleted symbol has recorded callers` —
cleaner semantics, but a breaking change to the report-object flow, costs an
executor turn, and the delta honestly reports it absent until built.
